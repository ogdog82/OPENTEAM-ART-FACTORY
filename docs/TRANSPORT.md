# Artifact bridge: real bytes only

Enable only in this Art Factory orchestration with standalone `ARTIFACT_BRIDGE: ON`. PREPARER shares batch specs; GENERATOR sends the actual source image file to the generation review/EXTRACTOR. EXTRACTOR runs Python/Pillow, displays **four individually named PNGs** and transfers the real files (not merely filenames, text or unresolvable sandbox links) to extraction review/UPLOADER. UPLOADER opens actual pixels and commits four PNGs to GitHub. If any hop cannot open the file, report `BLOCKED_TRANSPORT` with the exact broken hop and STOP. Do not regenerate art just to repair broken transport. Browser extension image forwarding is a pilot, not yet proven live. Avoid source image uploads to Git history unless a tested alternative transport requires it.
