This Project is a reusable OpenTeam Art Factory, not a game project. The repository is https://github.com/ogdog82/OPENTEAM-ART-FACTORY on branch main. Each fresh chat MUST read `art/queue.json`, `art/STYLE.md`, and `AGENTS.md` from GitHub before doing its assigned work. Never claim transferred bytes or committed files without evidence. If binary transfers fail, report BLOCKED_TRANSPORT and stop. Do not substitute programmer art for finished art.
